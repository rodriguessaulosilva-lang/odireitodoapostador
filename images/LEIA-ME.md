# Imagens do site

Coloque as duas imagens nesta pasta com **exatamente estes nomes**:

| Arquivo | Onde aparece | Formato recomendado |
|---|---|---|
| `tela-casa-apostas.png` | No topo (hero), abaixo dos selos — mockup de celular | Vertical (retrato), ex: 600×1200px, PNG ou JPG |
| `homem-preocupado.jpg` | Seção "Ludopatia tem tratamento" | Horizontal (paisagem), ex: 1200×700px, JPG |

## Como funciona
- Os espaços das imagens **já estão prontos** no HTML.
- Enquanto as imagens **não existirem** na pasta, o site **esconde automaticamente** o espaço (não aparece imagem quebrada).
- Assim que você subir os arquivos com os nomes acima, as imagens aparecem sozinhas, com bordas arredondadas e sombra.

## Trocar o nome/posição
Se quiser usar outro nome de arquivo ou mudar o local, é só me avisar que ajusto o `src` das imagens no HTML.
